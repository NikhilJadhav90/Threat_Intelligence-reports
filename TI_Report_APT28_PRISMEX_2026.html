03 · Technical Analysis
PRISMEX Infection Chain — Four-Stage Suite

The PRISMEX campaign uses a four-component malware suite with a clear separation of concerns: each stage performs a discrete task and hands off to the next, minimising the footprint of any single component. The chain begins with a document-based initial access exploit and ends with an in-memory .NET C2 implant communicating through a legitimate cloud storage provider. Notably, APT28 infrastructure for this campaign was operational 14 days before public disclosure of CVE-2026-21509, strongly implying advance access to vulnerability research consistent with GRU intelligence capabilities.

01
Initial Access: PrismexSheet — Excel Dropper via OLE/MSHTML Zero-Days
The victim receives a spearphishing email with an RTF attachment exploiting CVE-2026-21509, a Security Feature Bypass in the Shell.Explorer.1 COM object (CLSID: EAB22AC3-30C1-11CF-A7EB-0000C05BAE0B). This requires no user interaction beyond opening the document. The exploit retrieves a malicious .LNK file from a WebDAV server; the LNK exploits CVE-2026-21513 (MSHTML nested iframe DOM trust abuse) to achieve sandbox escape. Separately, PrismexSheet is delivered as an Excel .xlsx dropper using VBA macros and drone inventory / price list lures targeting Ukrainian defense contacts. It extracts a steganographic payload from an embedded PNG.
T1566.001 — Spearphish Attachment T1203 — Exploitation CVE-2026-21509 T1059.005 — VBA Macro T1027.003 — Steganography
02
Staging: PrismexDrop — Native Dropper & Environment Preparation
PrismexDrop is a native PE binary that prepares the victim environment, drops the remaining PRISMEX components, and establishes two persistence mechanisms simultaneously: a scheduled task named "OneDriveHealth" (masquerading as a legitimate Microsoft maintenance task) and COM DLL hijacking via adwapi64.dll — a deliberate misspelling of the legitimate advapi32.dll. The COM hijack targets CLSID {68DDBB56-9D1D-4FD9-89C5-C0DA2A625392}, writing the malicious DLL path to HKCU\Software\Classes\CLSID\{68DDBB56...}\InprocServer32.
T1053.005 — Scheduled Task (OneDriveHealth) T1574.001 — DLL Search Order Hijack T1546.015 — COM Hijacking
03
Loading: PrismexLoader — Proxy DLL with Custom Steganography
PrismexLoader is a proxy DLL that mimics a legitimate system DLL, loaded via the COM hijack established in the previous stage. It reads a PNG file from disk and extracts a hidden .NET assembly using a custom algorithm designated "Bit Plane Round Robin" — a novel steganography technique not previously attributed to APT28 tooling. Critically, the .NET runtime is loaded entirely in-memory: no assembly file is ever written to disk, making file-based detection ineffective. The extracted .NET assembly is PrismexStager.
T1027.003 — Steganography (Bit Plane Round Robin) T1055 — Process Injection T1218.011 — Signed Binary Proxy Execution
04
C2: PrismexStager — Covenant Grunt via filen[.]io
PrismexStager is a .NET Covenant Grunt implant — an expansion of the MiniDoor/NotDoor (GONEPOSTAL) Outlook backdoor previously attributed to APT28. It beacons to attacker infrastructure by routing C2 traffic through filen[.]io, a legitimate end-to-end encrypted cloud storage service. Using a trusted platform with valid TLS provides natural cover for encrypted C2 traffic. In October 2025, this component executed a WIPER command deleting all files under %USERPROFILE%, demonstrating active sabotage capability beyond pure espionage. The JARM fingerprint for the primary C2 domain is: 1dd40d40d00040d00042d43d0000003d25bc6207ca8acd9652e99aa3724a08.
T1071.001 — Web Protocol C2 T1102 — Web Service Abuse (filen[.]io) T1573 — Encrypted Channel

WebDAV-delivered LNK payload bypasses MOTW controls that would otherwise flag files downloaded from the internet. Enables execution of the CVE-2026-21513 exploit without Windows SmartScreen intervention.
T1114.001
Local Email Collection
PrismexStager evolved from the MiniDoor/NotDoor (GONEPOSTAL) Outlook backdoor. Local email collection capability maintained in current variant — targets diplomatic/defense correspondence on victim hosts.
T1574.011 · T1574.001
DLL Hijacking Variants
adwapi64.dll placed in DLL search-order priority position. The misspelling of advapi32.dll is a deliberate analyst trap — automated tooling scanning for advapi32 will not surface the malicious DLL. Consistent with APT28 operational security discipline.

08 · Mitigation
Actionable Recommendations
  • 1
    IMMEDIATE — Block
    Block or alert on outbound connections to wellnesscaremed[.]com, freefoodaid[.]com, longsauce[.]com, wellnessmedcare[.]org, and chickenkiller[.]com at DNS and proxy layers. Add IPs 159[.]253.120.2 (CERT-UA confirmed) and 193.187.148.169 to blocklists. Do not block filen[.]io wholesale without business justification review — it is a legitimate service — instead alert on unusual processes (explorer.exe, powershell.exe) initiating connections to filen[.]io subdomains.
  • 2
    IMMEDIATE — Hunt
    Hunt for the scheduled task name "OneDriveHealth" across all endpoints — especially where the task action path points to \AppData\, \Temp\, or \ProgramData\. Search the filesystem for adwapi64.dll — no legitimate software uses this filename. Audit HKCU\Software\Classes\CLSID for the key {68DDBB56-9D1D-4FD9-89C5-C0DA2A625392} — its presence is a near-certain indicator of compromise.
  • 3
    IMMEDIATE — Patch
    Patch CVE-2026-21509 and CVE-2026-21513 immediately across all endpoints. If patching is delayed, implement email gateway rules to block RTF attachments from external senders and quarantine LNK files delivered within archives. Disable MSHTML (Internet Explorer mode) where not required to reduce CVE-2026-21513 attack surface.
  • 4
    SHORT-TERM — Detection
    Deploy all three Sigma rules from Section 07 in your SIEM. Enable ETW (Event Tracing for Windows) monitoring for CLR runtime loads in non-development processes — in-memory .NET assembly injection by PrismexLoader will appear as unusual CLR activity in explorer.exe or similarly unexpected host processes. This is the primary detection path for the file-less stage.
  • 5
    SHORT-TERM — Email
    Implement email gateway rules to quarantine RTF attachments with embedded OLE objects from external senders. Flag and sandbox LNK files delivered inside ZIP/RAR archives. Consider blocking WebDAV access from email links — CVE-2026-21509 relies on reaching an attacker-controlled WebDAV server for the second-stage LNK payload.
  • 6
    SHORT-TERM — Subnet Pivot
    Expand hunting across the 23.227.202.x/24 subnet — IPs .138, .165, .141, .116 all show varying degrees of association with this campaign. The subnet is on Hivelocity (ASN 29802). IPs .165 (8 vendor flags, active Havoc C2 login panel) and .138 (sharedStrings.xml cross-link) are highest priority for enrichment. IP 193.187.148.247 (M247 Frankfurt) confirmed malicious — add to blocklist.
  • 7
    MEDIUM-TERM — Architecture
    Implement application allowlisting (WDAC/AppLocker) to prevent COM hijacking via user-writable paths. Enforce User Account Control at maximum level for all non-administrative users. Audit and restrict which processes are permitted to create scheduled tasks — alert on any task creation from PowerShell, cmd.exe, wscript.exe, or mshta.exe parent processes.
  • 8
    MEDIUM-TERM — Awareness
    Brief Ukrainian defense partners, Polish rail logistics staff, Romanian maritime operators, and Slovak/Czech ammunition initiative personnel on targeted spearphishing campaigns using drone inventory and defense procurement lures. This campaign specifically exploits the operational context of Ukraine war support logistics — brief staff that Excel files related to drone pricing or inventory are a confirmed lure category.
  • 9
    ONGOING — Wiper Awareness
    This campaign carries active sabotage capability: the October 2025 wiper command deleted all files under %USERPROFILE%. Ensure offline or immutable backups exist for all endpoints in targeted sectors. If a host is suspected to be compromised by PrismexStager, treat it as a potential wiper target and isolate immediately rather than allowing continued operation during investigation.
