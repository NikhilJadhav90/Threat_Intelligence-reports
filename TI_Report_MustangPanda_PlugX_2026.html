A cluster of PRC-aligned threat actors — tracked under the overlapping monikers Mustang Panda, TA416, UNC6384, and RedDelta — conducted a sustained multi-theatre espionage campaign between December 2025 and April 2026. The campaign targeted diplomatic, governmental, and critical infrastructure entities across Southeast Asia, Europe, and the Middle East using updated variants of the PlugX backdoor (SOGU.SEC). Infection chains evolved rapidly, cycling through adversary-in-the-middle (AitM) captive-portal hijacks, OAuth redirect abuse, MSBuild-based DLL side-loading, and malicious Windows shortcut (.LNK) lures. Active C2 infrastructure has been identified on ASN 149440 (Evoxt Enterprise) behind Cloudflare origin masking. 14 domains assessed to be part of ongoing staging infrastructure were identified, the majority previously unreported. Defenders should treat any .LNK or .CHM delivery associated with fake plugin update themes as high-confidence PlugX delivery attempts.

03 · Technical Analysis
Infection Chain Detail

The campaign demonstrated exceptional operational flexibility, deploying at least three distinct delivery variants during Q1 2026 against different target sets. The core payload — PlugX / SOGU.SEC — remained constant, while the delivery mechanism evolved to evade detection and adapt to target environments.

01
Initial Access: AitM Captive Portal Hijack
The target's browser performs a captive portal connectivity check. Compromised edge devices on the victim network intercept the request and redirect to a threat-actor controlled landing page served over HTTPS with a valid Let's Encrypt TLS certificate. The page impersonates a legitimate software update site.
T1557 — AitM T1566.002 — Spearphish Link T1189 — Drive-by Compromise
02
Delivery Variant B: OAuth URL Redirect Abuse
Phishing emails link to Microsoft's legitimate OAuth authorization endpoint (login.microsoftonline.com). When clicked, the OAuth flow redirects to an attacker-controlled domain and downloads a malicious archive. Legitimate OAuth URLs bypass conventional phishing defenses that blocklist known-bad links.
T1566.001 — Spearphish Attachment T1550.001 — Token Impersonation
03
Delivery Variant C: Malicious .LNK / CHM
ZIP archives containing Windows shortcut (.LNK) files impersonating PDF documents (e.g., photo_2026-03-01_01-20-48.pdf.lnk) are delivered by email. The LNK exploits ZDI-CAN-25373 for code execution without user interaction beyond double-click. CHM variants also observed in Middle East-targeting activity with Arabic-language missile-attack lures.
T1036.007 — Double Extension Masquerade T1218.001 — CHM Execution
04
Staging: STATICPLUGIN Downloader
AdobePlugins.exe — a digitally signed first-stage downloader signed by "Chengdu Nuoxin Times Technology Co., Ltd" (GlobalSign cert) — retrieves an MSI package disguised as media content. At least 25 malware samples share this code-signing certificate across related activity.
T1553.002 — Code Signing T1027 — Obfuscated Files
05
DLL Side-Loading: CANONSTAGER via cnmpaui.exe
The MSI installs components into %AppData%\BaiduNetdisk mimicking a legitimate cloud app. CANONSTAGER is side-loaded by the legitimate signed Canon IJ Printer Assistant Tool (cnmpaui.exe). CANONSTAGER uses API hashing and Thread Local Storage for function pointers to avoid behavioural detection, then decrypts cnmplog.dat (RC4, 16-byte key: eQkiwoiuDsvIPsmd) and injects PlugX into cnmpaui.exe's memory.
T1574.002 — DLL Side-Loading T1055.001 — Process Injection T1140 — Deobfuscate
06
Persistence & Privilege Escalation
A Registry Run Key named "BaiNetdisk" pointing to the malicious ShellFolder.exe is created via reg.exe or RegSetValueExA. PlugX contains Fodhelper UAC bypass logic to gain elevated privileges. The payload can additionally register as a Windows Service ("Microsoft Desktop Dialog Broker").
T1547.001 — Run Key Persistence T1543.003 — Create/Modify Service T1548.002 — Fodhelper UAC Bypass
07
C2 Communications
PlugX establishes HTTPS C2 on port 443 to infrastructure on ASN 149440. DNS-over-HTTPS (via dns.google) resolves C2 domains to evade network-layer blocking. Active services also observed on ports 3389 (RDP) and 5985 (WinRM) on C2 IPs. Cloudflare acts as a reverse proxy, masking the true origin IP. JA4x TLS fingerprint: dc020972a4a8_9fb583da09a2_fb02ba79e164.
T1071.001 — Web Protocols T1572 — Protocol Tunneling (DoH) T1090.001 — Internal Proxy
04 · ATT&CK Mapping
MITRE ATT&CK Techniques
T1566.001 / T1566.002
Spearphishing
Attachment-based (ZIP/LNK/CHM) and link-based (OAuth redirect) phishing against diplomatic targets. Lures impersonate U.S. diplomatic summaries and foreign ministry communications.
T1574.002
DLL Side-Loading
Abuses legitimate signed Canon printer executable (cnmpaui.exe) to load CANONSTAGER. Common across all three actor clusters. Also observed with GData DLL sideloading variant.
T1055.001
In-Memory Process Injection
CANONSTAGER injects the PlugX payload entirely in-memory into a trusted, signed process. No payload dropped to disk post-injection — evades file-based detection entirely.
T1553.002
Code Signing Abuse
First-stage downloader signed with GlobalSign cert issued to "Chengdu Nuoxin Times Technology Co., Ltd." At least 25 samples share this certificate across the cluster.
T1572 / T1071.001
Protocol Tunneling & C2
C2 over HTTPS port 443. DNS-over-HTTPS (dns.google) used for C2 domain resolution — bypasses both DNS-layer monitoring and blocklists. Internal proxy relay between victims.
T1548.002
Fodhelper UAC Bypass
Classic UAC bypass via fodhelper.exe for privilege escalation to SYSTEM. Allows PlugX to install as a service and maintain elevated persistence without triggering UAC prompts.
T1027.016
Mixed Boolean Arithmetic Obfuscation
PlugX variant employs control flow flattening and mixed boolean arithmetic (MBA) to complicate static and dynamic analysis. Junk code insertion further obscures logic.
T1213 / T1083
Data Collection
PlugX Disk plugin searches for documents matching *.doc*, *.pdf* extensions. System fingerprint command harvests OS version, hardware, and checks for Bitdefender (bdagent.exe) presence.

07 · Mitigation
Actionable Recommendations
  • 1
    IMMEDIATE — Block
    Block or alert on outbound connections to ASN 149440 (Evoxt Enterprise) on ports 443/3389/5985. Enrich the 14 C2 domains in the cluster before hard-blocking due to possible Cloudflare shared hosting. IP 108.165.255[.]97 should be blocked immediately — dedicated threat actor VPS confirmed.
  • 2
    IMMEDIATE — Hunt
    Search endpoint logs for the BaiNetdisk Run Key (HKCU\...\Run\BaiNetdisk) and any execution of cnmpaui.exe loading non-Canon DLLs. Search for the filename cnmplog.dat anywhere on the filesystem. These are high-fidelity, low-noise hunt queries.
  • 3
    SHORT-TERM — Detection
    Deploy the Sigma rule from Section 06 in your SIEM. Additionally, create a DNS query alert for any internal host resolving via dns.google (8.8.8.8 / 8.8.4.4) on port 443 — this is the DoH C2 channel. Legitimate use of DoH should be centrally managed, not client-initiated.
  • 4
    SHORT-TERM — Email
    Implement email gateway rules to quarantine ZIP attachments containing .LNK files, and CHM files from untrusted senders. Specifically flag double-extension patterns (*.pdf.lnk). Block or sandbox OAuth redirect links traversing microsoft OAuth endpoints that redirect to non-Microsoft domains.
  • 5
    SHORT-TERM — Policy
    Disable CHM/HTA execution via AppLocker or WDAC for standard users. Enforce UAC on Secure Desktop (prevents Fodhelper bypass). Review and audit all services named "Microsoft Desktop Dialog Broker" — this is a known PlugX service masquerade name.
  • 6
    MEDIUM-TERM — Awareness
    Brief diplomatic and government staff on lures impersonating U.S. diplomatic briefings and foreign ministry documents. The campaign specifically exploits the authority of U.S. attribution in diplomatic contexts — a social engineering angle unique to this actor cluster. Add geopolitical conflict lures (Middle East, Taiwan) to awareness training.
  • 7
    MEDIUM-TERM — Architecture
    Implement TLS inspection for outbound HTTPS on all critical assets to detect C2 communications masked by valid certificates. Deploy a centrally-managed DoH resolver and block direct DoH from endpoints. Monitor and alert on the JA4x fingerprint dc020972a4a8_9fb583da09a2_fb02ba79e164 in network logs.
  • 8
    ONGOING — Intel
    Subscribe to and ingest ThreatFox and Feodo Tracker feeds into your MISP/SIEM for continuous IOC updates on this cluster. Track the NameCheap + NameSilo + ASN 149440 + nginx/1.26.3 or 1.28.0 + Cloudflare pattern as a reliable infrastructure fingerprint — new domains will follow the same procurement pattern.
